# Installation

Use Windows and a UE4SS build compatible with the installed version of *The Last Caretaker*. The development reference is game 0.10.0.653173, Steam BuildID 25982825 and UE4SS 3.0.1 Beta Git SHA 527a483b.

1. Close the game. In Steam, open the game's **Properties → Installed Files → Browse**. The game root contains the inner **Voyage** folder.
2. Extract the entire **ShipNetAutomation** release ZIP into that root. Merge the existing **Voyage** folder so the Lua mod, Unreal packages and catalogue descriptor land in their respective folders.
3. Launch the game and open Engineering research. Check for **Winch Automator Basic** and **Winch Automator Advanced**.

Extract the replacement ZIP into the same root when updating. Use the game to empty and dismantle the automators before removing the mod from a save you want to continue using. Back up that save before uninstalling.
