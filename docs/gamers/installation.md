# Installation

Install [UE4SS for The Last Caretaker](https://www.nexusmods.com/thelastcaretaker/mods/4?tab=files) for your game version. For Update 6, use **UE4SS TLC UE5 8** (v1.3). Close the game before installing or updating the mod.

## Vortex

Manage *The Last Caretaker* with the [Vortex game extension](https://www.nexusmods.com/site/mods/1624). Starting with Ship Net Automation **0.1.1**, click **Mod Manager Download** on the [Nexus Files tab](https://www.nexusmods.com/thelastcaretaker/mods/454?tab=files). If Vortex prompts you, enable and deploy the mod. If you already have the release ZIP, use **Install From File** in Vortex.

## Manual installation

1. Download the ZIP from [Nexus Mods](https://www.nexusmods.com/thelastcaretaker/mods/454?tab=files) or [GitHub Releases](https://github.com/umanamente/tlc-ship-net-automation-mod/releases).
2. In Steam, open **Properties → Installed Files → Browse**. Extract the ZIP's **Voyage** folder into the folder Steam opens and merge it with the existing **Voyage** folder.

Launch the game and look for **Winch Automator Basic** and **Winch Automator Advanced** in Engineering research.

## Update or uninstall

Update in Vortex if you installed through Vortex. For a manual update, repeat the extraction step and replace the existing files when prompted. Before uninstalling, empty and dismantle the automators in-game and back up any save you want to keep using.
