# Changelog

## 0.1.0

- Adds Basic and Advanced Winch Automators to Engineering research and the Build menu.
- Adds on-device controls, catch and power readouts, and translations for 14 game languages.
- Supports automatic hauling near net capacity, manual hauling, and powered unloading to the Advanced cabinet.
- Records the running game version and Steam BuildID for release and compatibility checks.

- Gameplay check on 2026-11-24 confirmed that both Winch Automator Basic and Advanced work.
