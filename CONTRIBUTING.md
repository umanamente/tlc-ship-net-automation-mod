# Contributing

Use [the local development setup](docs/maintainers/development.md) to prepare your environment. Describe which device, game BuildID and UE4SS build you tested. For gameplay fixes, include the observed symptom and the conditions that reproduce it.

Use Conventional Commits for pull request titles. Include regenerated assets and their manifest when changing an input to the [asset pipeline](docs/maintainers/asset-pipeline.md). Consult the [ADRs](docs/maintainers/adr/README.md) before changing a documented design decision.
